# Studify_OOP

1. Project Title
Studify: An Adaptive Study Strategy and Progress Tracking System.

2. Project Description
Studify is an Object-Oriented Programming (OOP) application designed to help students organize study materials, manage quizzes, track progress, and improve learning efficiency. The system provides an easy-to-use platform for educational activities and academic management.

3. Problem Being Addressed
Many students struggle to organize study resources, monitor learning progress, and assess their understanding through quizzes. Existing methods are often scattered across different applications or rely on manual tracking. Studify aims to provide a centralized solution for managing academic activities.

4. Project Objectives
Develop a study management system using OOP principles.
Allow users to organize and access study materials.
Provide quiz features for self-assessment.
Track student progress and performance.
Create a user-friendly educational platform.
